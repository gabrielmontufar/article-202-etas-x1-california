# Data and rights status

The catalogue source is USGS ComCat/ANSS, with contributing networks, captured at the manuscript's documented cutoff. Exact input paths and SHA-256 are in provenance. The terrestrial domain combines Natural Earth land and SCSN/NCSN network boundaries. A specific redistribution licence for the SCEDC boundary was not established in the prior rights review. This release therefore does not bundle that boundary, derived masks, raw catalogue databases or prepared histories.

Public availability of a web URL does not establish redistribution permission. Provider terms and access URLs are in docs/DATA_PROVIDER_TERMS_20261025.md. The deterministic dummy fixture does not use those inputs. This release is a source/result companion, not a complete frozen-input data deposit; no deposit DOI is assigned.
