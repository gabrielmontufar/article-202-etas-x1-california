# Release limits

This release contains preserved historical source, saved results, a working archived-result inspection example and a deterministic numerical-kernel example. It does not contain raw catalogues, boundaries, derived masks, correspondence, credentials or manuscript drafts. The example was checked in an existing Python 3.13.17 environment; historical version records are retained separately.

The exact historical R6 program requires frozen inputs, guards, receipts and Windows paths. A complete clean-start numerical reconstruction is not certified, especially across the carried revision-2 fit. Do not remove its guards merely to claim portability. Public availability of this package would permit source and result inspection, but would not establish predictive skill, resolve H08 or guarantee the editor accepts the reproducibility limits. No full simulation is authorised by preparing this release.

The author approved publication and the MIT/CC BY 4.0 licensing scope on 25 October 2026. Scientific limits and input-access limits remain as stated.
